omarchy.org · landing page · two directions

Two ways to rebuild the Omarchy landing page.

Same content, same order, same logo and tagline as omarchy.org today — two different visual arguments for what that page should feel like. Every one is live and fully interactive: pick a theme and the entire page repaints, wallpaper included.

Themes

All 22 real Omarchy themes, palettes and wallpapers pulled straight from the repo. The picker previews each as three colours.

Structure

News → logo → tagline → lead → link grid → videos → footer. Unchanged from the live site.

Buttons

The flat row of 14 links becomes four groups — Install, Build, Gather, Back it — each owning a different theme colour.

Type

JetBrains Mono throughout, from hairline 100 to 800, doing the work a display face usually would.

Try this in each

Press T in the TTY for an fzf theme overlay, or use the filmstrip along the bottom of the Broadside. [ and ] step through themes in both.

Where the pixels come from

Palettes are parsed from each theme's colors.toml; wallpapers are the real backgrounds, re-encoded and embedded so the pages work with no network.

Still to decide

Which of the two carries the brand — and whether the theme picker belongs in a status bar or a persistent rail.
